核心領域：通膨、房價與青年就業數據分析報告

一、 本研究調取之 AREMOS 指標概述

依據從台灣 AREMOS 經濟統計資料庫篩選之月度資料（1991年01月至2025年12月），本研究選定以下核心變數進行交叉實證分析：

AREMOS 代號 指標中文名稱 (基期: 110年=100) 在青年就業與總體經濟研究中的代表性與定位
CPISA.m 消費者物價指數 (經季節調整) - 總指數 用以計算整體實質購買力，排除季節性波動。
CPI@FOOD.m 消費者物價指數 - 食物類 民生必需品通膨指標，青年對此類支出具有極高剛性需求。
CPI@HOUS.m 消費者物價指數 - 居住類 直接反映房租及住宅維修成本，反映日常居住成本擠壓。
CCI.m 營造工程物價指數 - 總指數 作為房價與房市擴張之供給端代理變數 (Proxy)，具備領先資產價格特性。
AE@TRA.m 受僱員工每人每月薪資 - 批發及零售業 青年就業主力行業（一），代表一般基層服務業名目薪資。
AE@EAT.m 受僱員工每人每月薪資 - 住宿及餐飲業 青年就業主力行業（二），典型具低薪、高工時與高通膨敏感性特徵。
AE@SUSV.m 受僱員工每人每月薪資 - 支援服務業 青年就業主力行業（三），包含派遣與商務支援，受景氣循環波動顯著。

二、 創新性專題研究題目設計

題目 1： 台灣民生 CPI 波動與營造物價對青年受僱員工實質購買力之跨期擠壓效應——基於向量自我迴歸 (VAR) 之衝擊反應分析

研究焦點： 著重於探討外部成本與資產市場擴張（CCI）如何伴隨結構性通膨（食物、居住），在時間序列上對服務業（住宿餐飲、批發零售）名目薪資調整產生落後影響，並估算實質購買力的淨流失幅度。

題目 2： 結構性物價衝擊對內需服務業勞動力薪資非對稱調整之機器學習與 SHAP 解釋模型——結合總體經濟計量與 AI 歸因

研究焦點： 導入 AI 結合計量模型。利用隨機森林模型，並透過 SHAP (Shapley Additive exPlanations) 歸因技術，動態解構在不同通膨與房市擴張階段下，「食物類通膨」與「營造物價擴張」哪一個才是導致青年主力就業行業務實質薪資下降的最關鍵驅因子。

三、 研究假說 (Hypothesis) 與經濟學理傳導機制

1. 研究假說

  • 假說 H1： 營造工程物價（CCI）與居住類物價（CPI@HOUS）的上升，對住宿餐飲及批發零售業之實質薪資存在顯著且持續的負向跨期擠壓效應。
  • 假說 H2： 青年密集就業之三大服務業名目薪資具有「工薪剛性」，其調薪幅度的非對稱落後，導致在結構性通膨期間，青年實質購買力流失呈現非線性加速。

2. 總體經濟學理傳導機制

第一階段：供給端成本轉嫁與資產財富效應
營造工程指數（CCI）大漲拉動居住類指數（CPI@HOUS）與租金走高。對服務業僱主而言，店租與食材成本雙重飆升，壓迫其利潤空間，使其缺乏為基層青年員工大幅調薪的財務餘裕。

第二階段：消費者預算約束與結構性擠壓
由於食物與居住為剛性生存需求，青年員工不得不提高這兩項消費的支出權重，產生強烈的「擠壓效應」。即便名目薪資微幅增長，其調幅仍落後於民生物價上漲速度。

第三階段：工資-物價螺旋失衡
在統計學上，這表現為時間序列中 CCI 與 CPI 領先對名目薪資投射衝擊，而住宿餐飲業等實質薪資在脈衝響應圖中呈現長期無法回復的負向偏離，驗證青年世代面臨「變相減薪」的經濟學現狀。

四、 數據視覺化圖表建議

  • 雙 Y 軸折線圖： 左軸置營造工程指數 (CCI.m) 與居住類指數 (CPI@HOUS.m)，右軸置三大服務業的「實質薪資」，直觀展示出資產物價攀升與實質薪資下行之間的交叉走勢。
  • 脈衝衝擊反應圖 (IRF Plot)： 配合 VAR 計量模型，模擬當 CCI 或 CPI@FOOD 發生一單位的正向標準差衝擊時，住宿餐飲業實質薪資在未來 12 到 24 個月內的跨期動態反應軌跡。
  • 特徵重要性與 SHAP 蜂群圖 (SHAP Beeswarm Plot)： 運行隨機森林模型後使用 SHAP 套件繪製，清晰呈現各項民生物價（食物、居住、營造）對實質薪資被稀釋的動態貢獻度。

五、 Python 資料清洗與計量/時間序列/AI分析完整程式碼

以下為專門針對 AREMOS CSV 資料格式設計的完整 Python 程式碼，包含資料清洗、實質薪資轉換、OLS 迴歸、VAR 時間序列模型以及最新的 SHAP 歸因分析實作：

# -*- coding: utf-8 -*-
import pandas as pd
import numpy as np
import statsmodels.api as sm
from statsmodels.tsa.api import VAR
from sklearn.ensemble import RandomForestRegressor
import shap

# 1. 讀取並清洗 AREMOS CSV 資料
df = pd.read_csv("YOUR_AREMOS_DATA.csv", skiprows=3)  # 依實際檔案結構調整跳過行數
df.columns = [col.strip() for col in df.columns]

# 轉換日期格式 (例如將 199101 轉換為 datetime)
df['DATE'] = pd.to_datetime(df['DATE'].astype(str), format='%Y%m')
df.set_index('DATE', inplace=True)

# 確保所有分析數值皆為 float 格式
cols_to_convert = ['CPISA.m', 'CPI@FOOD.m', 'CPI@HOUS.m', 'CCI.m', 'AE@TRA.m', 'AE@EAT.m', 'AE@SUSV.m']
for col in cols_to_convert:
    df[col] = pd.to_numeric(df[col], errors='coerce')

# 處理時間序列缺失值（使用前後向填補）
df.fillna(method='ffill', inplace=True)
df.fillna(method='bfill', inplace=True)

# 2. 經濟學變數轉換：計算「實質薪資 (Real Wages)」
df['REAL_WAGE_EAT'] = (df['AE@EAT.m'] / df['CPISA.m']) * 100
df['REAL_WAGE_TRA'] = (df['AE@TRA.m'] / df['CPISA.m']) * 100

# 計算年增率 (YoY) 以消除長期趨勢，適用於標準計量與 OLS
df['CCI_YoY'] = df['CCI.m'].pct_change(12)
df['CPI_FOOD_YoY'] = df['CPI@FOOD.m'].pct_change(12)
df['REAL_WAGE_EAT_YoY'] = df['REAL_WAGE_EAT'].pct_change(12)

df_clean = df.dropna()

# 3. 基礎計量分析：普通最小平方法迴歸 (OLS)
X_ols = df_clean[['CCI_YoY', 'CPI_FOOD_YoY']]
X_ols = sm.add_constant(X_ols)
y_ols = df_clean['REAL_WAGE_EAT_YoY']

ols_model = sm.OLS(y_ols, X_ols).fit()
print("=== OLS 迴歸分析結果 ===")
print(ols_model.summary())

# 4. 高級計量分析：向量自我迴歸模型 (VAR) 與脈衝響應
var_data = df_clean[['CCI.m', 'CPI@FOOD.m', 'AE@EAT.m']].apply(np.log).diff().dropna()
var_model = VAR(var_data)
var_results = var_model.fit(maxlags=12, ic='aic')
print("\n=== VAR 模型分析結果 ===")
print(var_results.summary())

# 5. 繪製學術規範必備的脈衝衝擊反應圖 (IRF)
irf = var_results.irf(periods=12)
# 在 Jupyter Notebook 中取消註解下行可輸出 IRF 圖
# irf.plot(orth=True)

# 6. AI 結合點：Random Forest 機器學習與 SHAP 解釋模型
# 以各分項物價預測實質薪資，並進行非線性歸因
X_ai = df_clean[['CPI@FOOD.m', 'CPI@HOUS.m', 'CCI.m']]
y_ai = df_clean['REAL_WAGE_EAT']

rf_model = RandomForestRegressor(n_estimators=100, random_state=42)
rf_model.fit(X_ai, y_ai)

# 計算 SHAP 值
explainer = shap.TreeExplainer(rf_model)
shap_values = explainer.shap_values(X_ai)

print("\n=== AI 與 SHAP 分析完成 ===")
print("[系統提示] 機器學習模型特徵重要性：", rf_model.feature_importances_)

六、 本專題 AI 與計量模型結合之評估建議

在專題的推進上，建議採取雙軌驗證：先用傳統計量模型跑出時間序列上的跨期傳導鏈結（VAR 脈衝響應）；接著，將數據輸入至隨機森林模型中並引用 SHAP 套件。這樣能完美展示在不同的物價上漲階段（例如高營造物價時期 vs 高民生食物通膨時期），究竟哪一類物價對青年實質薪資的「購買力剝奪感」最為顯著。這不僅能大幅提升專題報告的學術深度，更能精準展現 AI 在經濟研究中的落地應用。
