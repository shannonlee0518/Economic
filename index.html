AI 與總體經濟研究專題報告

淡江大學《AI與經濟研究報告》專案模組 · 基於台灣 AREMOS 資料庫與機器學習分析

📌 專題背景與 AREMOS 指標設定

核心領域： 通膨、房價與青年就業（跨期擠壓效應）
AREMOS 檢索指標： CPISA.m (消費者物價總指數)、 CPI@FOOD.m (食物類)、 CPI@HOUS.m (居住類)、 CCI.m (營造工程物價指數)；
青年就業薪資指標： AE@TRA.m (批發及零售業)、 AE@EAT.m (住宿及餐飲業)、 AE@SUSV.m (支援服務業)。

💡 任務一：具學術規範之創新性研究題目設計

題目 1：《台灣民生通膨與營造工程成本對低薪行業實質薪資之跨期擠壓效應：基於機器學習可解釋性模型 (SHAP) 的非線性分析》

創新點： 傳統計量模型（如 OLS）難以捕捉物價衝擊對薪資的非線性臨界點。本研究引入 AI 的 SHAP (Shapley Additive exPlanations) 架構，動態解構在不同通膨階段，究竟是「居住類 CPI」還是「食物類 CPI」對青年高度聚集的低薪行業（如住宿餐飲業）實質購買力下降的邊際貢獻度最大。

題目 2：《營造工程物價與居住通膨對青年核心就業行業的結構性衝擊：基於向量自我迴歸 (VAR) 的動態衝擊反應分析》

創新點： 將營造工程物價指數（CCI）作為房地產市場供給端的領先指標，結合居住類 CPI，探討當營造端與消費端物價雙重上揚時，利潤空間較小的批發零售與支援服務業等青年就業主力的薪資調整是否存在「工資黏性 (Wage Rigidity)」與遞延惡化效應。

🔬 任務二：研究假說 (Hypothesis) 與經濟學理傳導機制

📋 研究假說 H1

當營造工程物價（CCI）與居住類 CPI 顯著上升時，青年核心就業行業（住宿餐飲、支援服務）的實質薪資將呈現非線性的加速下滑，且存在顯著的跨期遞延效應。

📋 研究假說 H2

食物類 CPI 的衝擊對短期實質薪資的擠壓最具即時性（無遞延）；而居住與營造物價的衝擊則具備長期黏性，對青年購買力的傷害呈現跨期累積效應。

⛓️ 經濟學理傳導機制（Transmission Mechanism）

  1. 成本推動型通膨與利潤擠壓： 營造工程物價（CCI）上漲推升房屋重置成本與預期房價，透過租金及居住費用（居住類 CPI）傳導至服務業店面成本。利潤空間微薄的服務業廠商（如批發零售、餐飲）被迫進行成本轉嫁或凍結基層受僱員工的薪資調幅。
  2. 工資黏性與「變相減薪」： 由於名目工資具備向下黏性（Wage Rigidity），在物價總指數（CPISA）與食物類物價急遽噴發時，名目薪資未能等比例調整，直接導致勞工的實質購買力（Real Wage）遭到跨期擠壓。
  3. 要素流動與產業鎖定： 青年勞動力在短期內因技能鎖定，難以由低利潤率的支援服務業跨入高科技製造業，只能被動承受民生通膨與居住成本上升的雙重擠壓。

💻 任務四：Python 資料清洗、時間序列與基本迴歸分析草稿

請將從 AREMOS 匯出的 CSV 檔案放置於同一目錄下，運行以下分段優化的 Python 分析程式碼：

1. 資料清洗、日期轉換與「實質薪資」計算

import pandas as pd
import numpy as np
import statsmodels.api as sm
from sklearn.ensemble import RandomForestRegressor
import shap

# 1. 讀取 AREMOS CSV 數據 (跳過敘述橫列)
df = pd.read_csv('AREMOS_DATA.csv', skiprows=3)
df.columns = df.columns.str.strip()

# 2. 日期格式轉換
df['DATE'] = pd.to_datetime(df['DATE'].astype(str) + '01', format='%Y%m%d')
df.set_index('DATE', inplace=True)

# 3. 計算實質薪資 (名目薪資 / 物價總指數 * 100)
df['REAL_TRA'] = (df['AE@TRA.m'] / df['CPISA.m']) * 100
df['REAL_EAT'] = (df['AE@EAT.m'] / df['CPISA.m']) * 100
df['REAL_SUSV'] = (df['AE@SUSV.m'] / df['CPISA.m']) * 100

print(df[['CPISA.m', 'REAL_EAT', 'REAL_TRA']].head())

2. 基本計量經濟學分析：時間序列最小平方和迴歸 (OLS)

X = df[['CPI@FOOD.m', 'CPI@HOUS.m', 'CCI.m']]
X = sm.add_constant(X)
y = df['REAL_EAT']

model = sm.OLS(y, X).fit()
print(model.summary())

3. AI 進階應用：隨機森林結合 SHAP 解釋模型

X_ai = df[['CPI@FOOD.m', 'CPI@HOUS.m', 'CCI.m', 'CPISA.m']]
y_ai = df['REAL_EAT']

rf_model = RandomForestRegressor(n_estimators=100, random_state=42)
rf_model.fit(X_ai, y_ai)

explainer = shap.TreeExplainer(rf_model)
shap_values = explainer.shap_values(X_ai)
print("SHAP 計算完成，可使用 shap.summary_plot 繪圖。")
